# Plain Desk

Static SEO microsite for **Plain Desk** — South African treasurer / admin templates.

**Product CTA:** [Stokvel OS on Gumroad](https://stofficial.gumroad.com/l/ydbgne) (R199)

**Intended Pages URL:** https://esteprinsloo101-web.github.io/plain-desk/

## Contents

- `index.html` — home + guide list
- `blog/*.html` — five SEO guides
- `styles.css` — typography
- `robots.txt` / `sitemap.xml`

No build step. Serve the repo root on GitHub Pages.

## Rebuild from drafts

```bash
python3 _build.py
```

Drafts live at `/workspace/ops/seo-playbook/content/` on the authoring box.
